# SkillPath AI
A competition-ready student career platform built with HTML, CSS, JavaScript and a small Node.js/Express backend.

## Run locally
1. Install Node.js.
2. Open this folder in terminal.
3. Run: `npm install`
4. Run: `npm start`
5. Open: http://localhost:3000

The frontend works as a static demo too: open `public/index.html`.
The backend saves submitted resume profiles to `server/data.json`.

## What is included
- Career roadmaps
- Interactive skill test
- Resume/profile builder
- Job-readiness dashboard
- Career assistant
- Dark/light theme
- REST endpoints for health and profiles

For production, add authentication, a real database, server-side validation, rate limiting and an AI API on the server (never expose an API key in browser JavaScript).
